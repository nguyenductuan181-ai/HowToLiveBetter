Tải file EPUB

Trang này đã đọc được cả cuốn sách ngay trên trình duyệt. Nếu muốn đọc trên máy đọc sách hoặc app riêng thì tải file về.

Tải HowToLiveBetter-vi.epub (2,6 MB)

Bạn đang mở trong Zalo, Facebook hoặc Messenger. Các app này thường không tải được file .epub. Bấm nút ⋯ hoặc ⋮ ở góc màn hình, chọn «Mở bằng trình duyệt» rồi tải lại.

  • iPhone, iPad: tải xong mở app Tệp, chạm giữ file, chọn Chia sẻ rồi chọn Sách.
  • Android: cần một app đọc EPUB, ví dụ ReadEra hoặc Lithium.
  • Windows: dùng Calibre hoặc Thorium Reader. Trên Mac mở bằng app Sách.
  • Kindle: gửi file qua Send to Kindle, Kindle không mở trực tiếp file EPUB.
  • Boox, Kobo, PocketBook: chép file vào máy là đọc được.
